# EduBridge

Adaptive, inclusive learning platform for Indonesian students. Built around accessibility-first reading, local-first progress, and contextual learning assistance.

Live demo: https://razzironaldi.github.io/EduBridge/

## What it demonstrates

- Adaptive reading modes for dyslexia-friendly, focus, low-vision, and balanced use
- Keyboard-first navigation and visual focus tools
- Indonesian text-to-speech with adjustable speed
- Contextual glossary and learning assistant
- Quiz modes with spaced-repetition scheduling
- Local progress, bookmarks, notes, certificates, and JSON backup

## Tech stack

TypeScript · React · Vite · Zustand · React Router · Web Speech API · Node.js

## Run locally

```bash
npm install
npm run dev
```

Optional API configuration belongs in `.env.local`; never commit secrets.

## Project status

Working competition prototype. The public demo is the quickest way to review the product; the repository contains the implementation and proposal context.
